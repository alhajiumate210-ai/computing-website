# Department of Computing Website — Git and GitHub Assignment

## Project overview
A responsive sample website for a Department of Computing. It contains a Home page, About Us page, Programmes page, and Contact Us page. The contact form demonstrates client-side interaction only; it does not send messages to a server.

## Files
- `index.html` — homepage
- `about.html` — department overview
- `programmes.html` — sample computing programme areas
- `contact.html` — contact details and demonstration form
- `style.css` — shared responsive design
- `script.js` — contact form feedback
- `GIT_GUIDE.md` — Git and GitHub steps for the assignment

## Run the website
Open `index.html` in a web browser. No extra software is required to view the static website.

## Important
Replace sample programme names and placeholder contact information with verified information from your institution before submitting/publishing. Review the files and make sure you can explain them to your lecturer.
